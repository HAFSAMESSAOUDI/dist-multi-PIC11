## 💡 Astuces Overleaf

### Modifier le Rapport

**Si vous voulez modifier le texte:**

```
1. Cliquer dans la zone centrale (éditeur)
2. Modifier le texte LaTeX
3. Cliquer "Recompile"
4. Le PDF se met à jour automatiquement
```

### Naviguer dans le PDF

```
• Scroll: Faire défiler les pages
• Zoom: Boutons + / - en haut
• Page: Entrer numéro de page directement
• Sections: Cliquer dans table des matières (liens actifs)
```

### Voir les Erreurs

```
Si la compilation échoue:

1. Une icône ⚠️ apparaît en haut
2. Cliquer dessus pour voir les erreurs
3. Double-cliquer sur une erreur → va à la ligne du code
```

### Partager le Projet

```
1. Cliquer sur "Share" (en haut à droite)
2. Copier le lien "Read & Edit"
3. Envoyer à quelqu'un
4. Il peut modifier le rapport en temps réel (collaboratif!)
```

## 🆘 Dépannage

### Problème 1: "Compilation Failed"

**Cause:** Package LaTeX manquant
**Solution:**
```
1. Cliquer sur l'icône ⚠️ en haut
2. Regarder le message d'erreur
3. Généralement: Overleaf télécharge automatiquement les packages
4. Attendre 1 minute et cliquer "Recompile"
```

### Problème 2: "PDF ne s'affiche pas"

**Cause:** Navigateur bloque l'aperçu
**Solution:**
```
1. Télécharger le PDF quand même (icône 📥)
2. Ouvrir le PDF téléchargé
3. Ou rafraîchir la page Overleaf (F5)
```

### Problème 3: "Upload Failed"

**Cause:** Fichier trop gros ou connexion lente
**Solution:**
```
1. Vérifier la taille du fichier .tex (~150 KB)
2. Vérifier votre connexion internet
3. Réessayer l'upload
4. Ou copier-coller le contenu du .tex dans un nouveau projet
```

### Problème 4: "Accents français incorrects"

**Cause:** Encodage incorrect
**Solution:**
```
1. Le fichier .tex utilise déjà UTF-8
2. Normalement pas de problème
3. Si problème: Menu → Compiler → changer en "pdfLaTeX"
```
